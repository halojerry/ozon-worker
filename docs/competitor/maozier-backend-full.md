# 毛子ERP（ozon.maozierp.com）网页后台 全量前端源码反编译分析

> **分析对象**：`bootstrap2.js`（Vben Admin 主包，含路由树）+ 64 个懒加载 chunk（`chunks/`）+ 167 个文件全集（`all/`，含 SFC 拆分包与库文件）
> **API 基址**：`https://api.maozierp.com`（`app.config.js`）
> **框架**：Vben Admin Pro（Vue 3 + Vite + TailwindCSS + TS），表格 `vxe-table`，图表 `echarts`，富内容编辑器内含 Ozon JSON 排版引擎
> **产品定位**：Ozon 跨境卖家 ERP「网页后台」+「浏览器插件」双形态。本文档覆盖**网页后台**全部页面（插件部分另文分析）
> **方法**：从 JS 源码提取中文字符串与上下文，逐页还原字段、筛选、列、按钮、状态、弹窗。**所有字段均为源码中真实存在的字符串**，未臆造。

## 二、登录/注册模块

### 2.1 登录 `/auth/login`
- 页面标题：**Ozon智能上品工具**；副标题：**解放双手，让赚钱更轻松**
- 文案：**请登录 / 立即开始赚钱**
- 表单字段：
  1. **username 账号**（占位「请输入用户名」，必填）
  2. **password 密码**（VbenInputPassword，必填）
  3. **captcha 图形验证码**（自定义验证组件，阿里滑块 captcha，方法 `showCaptcha/verify/execute`）
- 交互：
  - 登录按钮（loading）
  - 显示「注册」入口（showRegister:true）、「忘记密码」入口（showForgetPassword:true）
  - **验证码登录 / 扫码登录已关闭**（showCodeLogin:false, showQrcodeLogin:false, showThirdPartyLogin:false）
  - 登录成功 toast：`authentication.loginSuccess` + realName 描述
- 页面结构：左侧品牌图（logo2.png/logoBlack.png 随暗色模式），右上角主题切换

### 2.2 注册 `/auth/register`
- 副标题：**让出单变得简单**
- 字段：
  1. **username 手机号**（placeholder 请输入手机号，maxlength 11，正则 `/^1[3-9]\d{9}$/`）
  2. **password 密码**（VbenInputPassword）
  3. **confirmPassword 确认密码**（VbenInputPassword）
  4. **sms_code 短信验证码**（VbenPinInput，发送验证码 → 图形验证）
  5. **agreePolicy 同意条款**（VbenCheckbox，含隐私政策/服务条款链接）
- 注册成功 toast：「注册成功，2秒后跳转到登录页」
- 登录态进入后台后默认落地页 = `app.defaultHomePath`（仪表盘）

### 2.3 忘记密码 `/auth/forget-password`
- 副标题：「请输入您注册时的手机号，我们将发送验证码到您的手机」
- 字段：
  1. **手机号**（11位校验）
  2. **短信验证码**（「获取验证码」按钮，发送后倒计时 `${e}s后重新发送`）
  3. **新密码**（至少6位）
  4. **确认新密码**（两次一致校验）
- 提交按钮：**确定**

### 2.4 验证码登录 / 扫码登录
- `/auth/code-login`：字段 phoneNumber + code（验证码）——被配置关闭，路由保留
- `/auth/qrcode-login`：Vben 默认扫码模板（配置关闭）
