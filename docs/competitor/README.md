## 🔍 复刻要点（两份全量文档的精华）

### 上品帮：页面结构借鉴
- **18 个一级菜单**：首页/商品刊登（采集箱·上架记录·上架配置·定时任务·手动上架模板）/线上商品（OZON·WB）/订单管理（我的订单·退货·大屏·统计·黑名单）/1688货源/内容管理（品牌·简介·图片·水印）/选品广场（大盘·中国馆·类目·热销·热词·标签反查·WB热销）/自动化助手/OZON消息/促销/下架重上/店铺分析/授权店铺/跨境定价（4 个定价器）/推广/VIP/子账号/设备
- **核心交互**：采集箱→上架记录（状态机）→异常重上/搬家；上架配置（多店铺差异化模板）；商品编辑页 7 大分区 20 主字段 + 8 列变体表；定时任务（间隔/分段）
- **计费**：1 帮豆/sku/店铺；搬家/编辑/手动各有消耗；AI 生成文本最低 7 积分、图片 6 积分/张

### 毛子ERP：交互与智能化借鉴
- **插件+后台双端**：后台承载重活（AI编辑/批量/数据），插件承载轻交互（前台商品页选品标签/一键上架悬浮窗）
- **AI 全链路上架**：采集 → AI 匹配类目 → DeepSeek 生成标题/描述/标签 → 中俄互译 → AI 套图（白底/场景/卖点/其他，40 毛豆/张）→ 校验上架
- **一键上架弹窗 11 字段**：店铺（多选+货币一致）/品牌/图片顺序/上架方式（防侵权 hand/强制 api）/水印/合并变体/浮动价格/货源/货号生成/售价倍率/划线价
- **选品规则 22 条件**：前台商品卡片自动打标变色 → 一键批量上架
- **订单 7 状态 + 消息模板**（催护照/催取货/索好评，俄语模板+占位符）

## 🎯 自有 WebUI 复刻路线（功能优先）

| 优先级 | 功能 | 对标 | 我们现状（v0.43） |
|---|---|---|---|
| **P0** | 上架配置模板（改价/货号前缀/水印/防侵权，多店铺差异化） | 上品帮 /upGoodsSetting | Worker 参数已有，缺 WebUI 配置层 |
| **P0** | 上架记录增强（状态机+异常重上+批量重传+导出） | 上品帮 /batchRecord | /tasks 只有进度 |
| **P0** | 采集箱批量上架（多选草稿→选店铺/配置→批量提交） | 上品帮 goodsCollect | Worker 批量能力已有，缺前端入口 |
| **P0** | 订单列表+采购/货源信息+利润列 | 两家 orderManage | Worker 有 ozon_order 数据，未接线 |
| **P1** | 多店铺差异化配置、商品搬家/下架重上、定时任务、在线商品批量操作 | 上品帮核心 | 全量重传天然支持 |
| **P2** | 榜单选品数据页、定价工具内嵌、消息/催评自动化、AI 套图扩展 | 毛子核心 | 数据通道已有，缺 UI |
| **P3** | 子账号权限、数据大屏、积分计费体系 | 两家 | 无 |

**核心洞察**：竞品 80% 功能是「Worker 已有能力 + WebUI 接线 + 配置层」——真正需要 Worker 新增的只有订单数据 API（若未接线）和消息模板。按 P0 → P3 推进即可。
