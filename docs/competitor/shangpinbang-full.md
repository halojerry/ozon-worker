## 0. 全局架构

### 0.1 技术栈与请求层

- **技术栈**：Vue 3 + Vue Router (hash) + Ant Design Vue + ECharts + xlsx.js（表格导出）
- **API 域名**：`https://plus.shopbang.cn`（业务 API）；`https://api.shopbang.cn`（老 API）；`https://plus.shopbang.cn`（图片/文件加速，`arraybuffer` 下载）
- **请求封装 `Fo(e,t)`**：统一 POST，自动附 `token`；返回 `{code, data, message}`
  - `code<0` 业务失败；`code=401` 登录失效 → 打开登录弹窗；`code=402` 设备同时在线数量过多 → `Modal.warning("设备同时在线数量过多，已强制退出")`
  - 超时 → `接口请求超时，请稍后！`；其他错误 → `系统繁忙，请重试！`
- **每 token 每分钟限流 ≤300 次**；并发 ≤50
- **超长请求豁免 300s timeout**：`/goods/onlineGoods/ozon/batchWatermark`、`/other/fanyi/translateVideo`
- **设备在线检测**：`/erpLogin/checkDevice`、`/open/getBrowserVersion`（登录弹窗白名单）

## 2. 商品刊登

### 2.1 采集箱/GoodsCollect

**页面用途**：商品采集数据的管理中心（插件采集、表格上架、手动创建商品），支持批量上架、定时任务、删除。

**筛选区（查询栏）**：
- 账号（选择账号，`User`：主账号/所有账号 + 子账号列表）
- 选择采集商城（`collect_type` 多选，来源枚举 `rt`：`1688` / `淘宝`(TB) / `天猫`(TM) / `亚马逊`(AMZ) / `WB` / `拼多多`(PDD) / `京东`(JD) / `TEMU` / `速卖通`(ALIE) / `手动创建`）
- 采集时间范围（近7天/近15天/近30天）
- 查询按钮

**工具栏按钮**：
- **批量上架**（按钮旁显示 `（ sku：N 个）`；二次确认弹窗）
  - 约束：仅支持采集来源为 OZON 或 WB 的商品；同一个采集商城的数据才支持批量上架；单次批量上架 sku 数量不得超过 **1000 个**
  - 上架后弹窗：`您已成功提交上架任务，可前往【上架记录】进行查看！`（按钮：前往查看/继续上架）
  - 帮豆不足 / 店铺上新额度不足提示
- **OZON表格上架**（弹窗，见下）
- **手动创建商品**（下拉菜单）：
  - **创建OZON商品** → 跳转路由 `CreateGoods`
  - **创建WB商品** → 跳转路由 `CreateWbGoods`
- **批量删除**（确认弹窗：`确定删除选中的商品吗？删除是永久删除，无法找回`）
- **上架教程**（视频教程外链）

**表格上架弹窗（表格数据）**：
- 说明文案：「支持三种方式填写表格」① 使用上品帮插件，批量导出商品表格，常用于整店搬家 ② 下载的模板表格，在模板里面按要求填写竞品代码和价格 ③ 上品帮自动化助手导出的表格
- **下载模板表格**（`表格上品-模板.xls`）
- **上传表格**（仅支持表格文件；表格不超过 **1000 条数据**）
- **示例**（表格列预览）：商品链接 / 销售价格 / 商品名称 / 商品图片
- **解析后的表格数据**（预览列）：竞品代码 goods_id / 货号 offer_id / 原价 origin_price / 改后售价 price / 改后划线价 old_price / 最低价 min_price / 重量(g) weight / 条形码(FBP)(选填) barcode / 操作
- 解析按钮：`解析表格数据，请耐心等待...`；未识别有效数据报错
- **货币单位选择**：人民币 / 美元 / 卢布 / 吉尔吉斯斯坦索姆 / 坚戈
- 上架提交后：帮豆不足 → `前往充值帮豆`；失败 → 弹窗 `失败 N 个，原因：xxx` + `查看失败商品`

**列表表格列**：
- 图片 primary_image
- 标题 name（显示主图/标题；点击跳转源商品）
- 采集来源 collect_type（图标+名称）
- 采集价格 origin_price（货币）
- sku数量 skuLength
- 货源信息 goods_source（货源地址 + 货源备注，可内联编辑）
- 上架价格（元） up_price
- 采集时间 create_time
- 更新时间 update_time
- 操作（每行）：
  - **一键上架**（`一键上架至{OZON/WB}平台`，绿色按钮）
  - **编辑上架**（紫色；会员限制「编辑上架为会员权益，请升级会员」；OZON 采集源需 `copy_status==2` 即「商品数据正在抓取中, 抓取完成后才能使用编辑上架（预计需要10分钟）」；二次修改商品后上架）
  - **手动上架**（弹窗：`手动完善商品信息上架`，上架到 OZON/WB 选择）
  - **查看采集商品**（跳转详情）
  - **点击跳转**（源链接）、**找货源**（需浏览器插件）
  - **删除**

**行内可编辑**：货源地址、货源备注（直接编辑保存）

**手动创建入口跳转**：`创建OZON商品` → `router.push(CreateGoods)`；`创建WB商品` → `CreateWbGoods`

### 2.2 上架记录/BatchRecord

**页面用途**：查看所有上架任务的结果与状态，支持异常重上、异常编辑、搬家、删除、释放帮豆、导出模版、密码查看。

**筛选区**：
- 账号（主账号/所有账号/子账号）
- 上架平台（`platform`：OZON/WB）
- 选择店铺（client_ids 多选）
- 选择上架状态（`status`）：上架中 / 上架完成 / 上架待校验 / 上架异常（+ 全部）
- 选择上架方式（`up_goods_type`）：一键上架(0) / 编辑上架(1) / 搬家(2) / 手动上架(3) / 异常编辑(4) / 下架重上(5)；另有隐藏方式6=一键上架（自动化）(ocType=auto)
- 输入货号 / 输入竞品代码（offer_id / goods_id）
- 上架时间范围（近7天/近15天/近30天）
- 查询 / 重置

**顶部信息条**：
- 今日上架的sku数量（`今日上架数量`）
- 只保留30天内的上架记录（vip？90天：30天，列表只返回30天数据）

**工具栏按钮**：

**榜单类型（模式，`oa`）**：

- 蓝海商品：该榜单列出了在销售过程中容易成交的产品，这些产品具有较高的购买意愿和易转化的特点。商家可以通过该榜单了解易出单产品，将重点放在这些产品上，提高转化率和订单成交量

**数据口径说明（Tooltip）**：
- 销量排名：按过去28天内销售量计算的商品排名。排名前1%的商品在平台上的销售量比其他99%的商品高
- 销售额排名：按过去28天内销售额计算的商品排名
- 商品卡片浏览量：买家在28天内打开商品卡片的次数
- 可用性：在时期的哪部分商品曾经有过现货。比如，如果在28天中的7天中商品有过现货，那么它的可售度将为25%
- 浏览量：天内在搜索结果和目录中的商品浏览量
- 日均销售额(ADS)：将28天内所有销售金额除以商品有现货的天数，退货和取消不纳入计算
- 日均订单量：将28天内所有订单数量除以商品有现货的天数
- 配送时间：将商品配送给买家的平均配送时间，根据28天内商品的所有订单来计算
- 加购率：加入购物车次数与在搜索结果中展示次数的比值
- 商品卡片加购率：商品卡片浏览次数与浏览后将商品添加至购物车的数量之间的比例
- 出单卖家数量：该产品过去28天内售出商品的卖家数量
- 月平均价格 / 月最低价格：该产品过去28天内的平均/最低价格
- 参与促销天数 / 折扣：商品近一个月参与促销的天数/平均折扣
- 促销活动的转化率：促销期间订购的金额在总订购金额的占比
- 付费推广天数：近一个月参与模版付费推广的天数
- 广告份额：商品推广费用在订单总额的占比
- 成交率：未取消且未退回的订单占比

## 20. 跨页交互流程与状态机

### 20.1 核心上架流程

```
[插件采集/表格上架/手动创建]
        │
        ▼
[采集箱 GoodsCollect] ──一键上架──▶ [上架记录 BatchRecord（状态机：上架中→上架完成/上架待校验/上架异常）]
   │  │                                 │               │
   │  ├──编辑上架──▶ [CreateGoods/CreateWbGoods] ◀──异常编辑──┘
   │  ├──手动上架──▶ [CreateGoods 手动上架模式]
   │  └──批量上架──▶ [提交任务 → 上架记录]
   │
   ├──OZON表格上架──▶ 上传表格解析 → 提交 → 上架记录
   └──创建OZON/WB商品──▶ CreateGoods/CreateWbGoods

[上架记录 BatchRecord]
   ├── 上架完成 → 可搬家（到WB/OZON）→ 弹窗选目标店铺
   ├── 上架待校验 → 校验按钮 → 再次查OZON → 可标记异常
   ├── 上架异常 → 异常重上 / 异常编辑（跳CreateGoods）
   └── 帮豆上架数据 → 释放帮豆（返还）

[CreateGoods 提交] ──▶ 校验 → 帮豆/额度检查 → [上架记录]查看状态
[CreateGoods 定时上架] ──▶ [定时任务管理 OrderTimingList] 状态机
[线上商品 GoodsManage] ──编辑商品──▶ CreateGoods（线上商品编辑模式）
[Reup 下架重上] ──重新上架──▶ 提交 → [上架记录]
```

### 20.2 订单状态流转

```
OZON: 等待注册→正在验收→等待确认→等待备货(1)→等待发运(2)→运输中(3)→已签收(5)
       └→ 护照信息收集(子状态) → 已到达取货点(子状态)
       ├→ 仲裁/快递客户仲裁/分拣中心未接受/由卖家发送（异常分支）
       └→ 已取消(6)（买家/卖家/Ozon 取消方；取消原因：仓库断货/其他/买家没取货等）

WB: 等待备货(1)→已准备发运(2)→运输中(3)→已签收(5)；有争议(4)分支；已取消(6)

操作对应：
  等待备货 → 备货按钮
  已准备发运(2) → 打印面单/交付物流(WB)
  运输中(3) → 查看物流/取消订单
  护照信息收集 → 催护照按钮
  已到达取货点 → 催取货按钮
  已签收 → 索好评按钮
```

### 20.3 上架状态机（BatchRecord）

```
上架中(1) → 上架完成(2/9) ──▶ 可搬家/可编辑
         → 上架待校验(3) ──▶ 校验 → 标记异常(8) 或 完成
         → 上架异常(8) ──▶ 异常重上 / 异常编辑 / 释放帮豆
```

### 20.4 定时任务状态机

```
待开始(pending) → 处理中(handling) → 已完成(completed)
     │ 取消上架(仅待开始)     │ 中断上架(仅处理中)
     └→ 已取消(canceled)       └→ 已中断(Interruption)
已完成/已取消/已中断 → 重新上架（生成新任务）
```

### 20.5 促销状态

```
活动列表：等待同步 → 正在同步 → 同步完成
商品：可参加商品 → 已参加商品（手动参加/自动参加）
   手动参加 → 可退出（退出活动）
   自动参加（OZON自动拉入） → 通过 SaleAutoMove 自动退出
退出：退出成功 → 回到可参加
```

### 20.6 店铺状态机

```
正常(1) → 冻结(0) → 解冻 → 正常
正常/冻结 → 异常(-1)
密钥：未获取 → 正常 → 快过期（≤10天）→ 已过期
Cookie：未添加 → 已添加 → 已失效
上新额度：总额度 / 今日额度剩余 / 总额度剩余
```
