# G2 方案：多 SKU 透传 + 1688 引流 SKU 剥离

> 生成：2026-08-20 · 基于 3 个真实 1688 产品实测（1063405325167 / 1060474931611 / 1065157103062）+ 2 个 Ozon 竞品（垃圾桶 32L/30L）

## 一、真实数据揭示的 SKU 三类形态

| 形态 | 产品案例 | 特征 | 上架策略 |
|---|---|---|---|
| **组合装+配件引流** | 1063405325167（14 变体） | 主品组合装 33-122 元 + 配件（拆豆盒 1.88/拆豆棒 0.85/静音垫 1.5）价格断崖 | **剥离配件**（不上），保留主品 |
| **角色款式** | 1065157103062（14 变体） | 不同 IP 款式 4.6-29.7 元，都是独立商品 | **全部上或采样**（无剥离需求） |
| **尺寸/款式** | 1060474931611（15 变体） | M01-M94 不同款式 5.97-13.49 元 | **全部上或采样** |

## 二、现有剥离的 3 个 gap（实测发现）

| Gap | 现状 | 问题 |
|---|---|---|
| **配件词缺失** | `_SKU_SKIP_KEYWORDS` 无「拆豆盒/拆豆棒/静音垫/工具」 | 1063405325167 的 4 个配件漏网（只滤掉 1 个「塑料小榔头」） |
| **价格规则失效** | `min < avg×0.3` 且 `max/min≥3` | 配件 0.85 vs 主品 122（144x 满足），但 `min=0.85 < avg(30)×0.3=9` 不满足（avg 被高价组合装拉高） |
| **数量变体误判** | 配件也被标 `variant_type=quantity` | 被当数量变体拆卡，而非剥离 |

## 三、G2 实现方案（skill 侧，两阶段）

### 阶段 1：剥离增强（`_filter_bait_and_custom_skus`）

1. **配件词扩充**：`_SKU_SKIP_KEYWORDS` 加配件类词（工具/配件/盒/棒/垫/锤/图纸/赠品/替换/零件/配件/散件）
2. **价格规则改进**：用「相对中位数」替代「相对平均」——`min_price < 中位数价格 × 0.3`（中位数抗极端值；实测 avg 被组合装拉高导致漏判）
3. **组合装识别**：名称含「+工具/包/套」等多段组合 → 视为组合 SKU 保留；纯配件名（不含主品核心词）→ 剥离
4. **主品核心词**：从标题提取（如「敲豆豆」/「手风琴」/「垃圾桶」）——配件名不含核心词才剥离，防误杀独立款式（1065157103062 角色款名称含核心词，保留）

### 阶段 2：max_skus 放开 + 采样

1. `discover/follow/batch_test` 三入口 `max_skus` 从 1 → 可配置（默认 5-8）
2. 复用 G1 已实现的 `_sample_values`（有图优先 + 价格距中位数近）
3. 剥离后变体数 > max_skus → 采样截断
